# Política de Privacidad — Pasaporte San Juan

**Nexar Sistemas**  
**Versión:** 1.1.0 · **Estado:** Vigente

## 1. Datos personales

El juego no solicita cuenta, nombre, correo, teléfono, contraseña ni otros datos personales. No está diseñado para identificar personalmente a quien juega.

## 2. Identificador local e historial

Al jugar se genera un UUID v4 aleatorio y se guarda en `localStorage` como `pasaporte-san-juan.player-token.v1`. Permite evitar repeticiones y conservar historial de partidas, puntajes, aciertos y rachas. No contiene nombre, email ni perfil. Si se borra el almacenamiento local, se genera otro token y el historial anterior deja de asociarse al navegador.

## 3. Backend y terceros

Supabase almacena el token, la fecha de última actividad y el historial indicado. El sitio puede publicarse mediante GitHub Pages. Ambos proveedores pueden procesar datos técnicos de acceso y seguridad conforme a sus propias políticas. No hay publicidad, analítica publicitaria, perfiles comerciales, venta de datos ni decisiones automatizadas sobre personas.

## 4. Cookies y seguridad

Nexar Sistemas no usa cookies propias para publicidad o seguimiento individual. `localStorage` se usa solo para el token técnico. Las operaciones del juego se validan en backend; aun así, Internet no permite garantizar seguridad o disponibilidad absolutas.

## 5. Menores, cambios y legislación

El juego es de entretenimiento general y no pide información personal de menores. Esta política podrá actualizarse ante cambios del producto o requisitos legales y se interpreta conforme a la legislación aplicable de la República Argentina.
